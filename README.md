# Сайт мини-игр

Описание
--------
Этот проект представляет собой веб-сайт с мини-играми. Сайт позволяет пользователям играть в различные увлекательные игры, такие как викторины и игры на угадывание.

Технологии
-----------
- HTML
- CSS
- JavaScript

Установка и запуск
------------------
1. Клонируйте репозиторий на свой локальный компьютер.
2. Откройте файл `index.html` в вашем веб-браузере.

Использование
-------------
- Перейдите на главную страницу, чтобы увидеть описание и инструкции.
- Нажмите на кнопку "Поехали!" чтобы начать играть в игры.
- Следуйте инструкциям на экране для каждой игры.
